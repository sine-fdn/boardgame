Data Sharing: Introduction

{{C.GAME_CONFIG.intro}}

This game simulates the scenario with the following rules:

  • {{C.GAME_CONFIG.num_of_players}} players participate in {{ C.NUM_ROUNDS }} rounds. You will be randomly assigned to a player role.
  • Each player starts with {{ C.INITIAL_UTILITY }}.
  • Players can contribute up to {{ C.DATA_POINTS }} Data Points per round, by selecting from four Data Sets.
  • Each Data Set has a Sharing Cost. This cost will be deduced from the player's Untility Points.

After all players make their contribution decisions, all Data Points are summed up, and multiplied by a factor of {{ C.MULTIPLIER }}. This reflects the added value created when data is combined.

This sum is then distributed among all players. However, the benefit from the use case is not distributed equally. Here is how the benefit is distributed:

Summary

In every round, you make one Contribution Decision: Decide how many Data Points to contribute to the use case using Data Sets. Each Data Point you contribute decreases your Utility Points but increases the utility of the group. Your goal is to make the most out of your Utility Points over the {{ C.NUM_ROUNDS }} rounds.
